# CECH-PUCP.pe
Estructura
----------
- index.html: portada.
- publicaciones.html: boletines + series de cuadernos + archivo.
- serie-china-antigua.html: presentación de Cuadernos de China Antigua y Medieval y números N.º 01–02.
- serie-microeconomia.html: presentación y número disponible.
- convocatorias.html: estructura demostrativa.
- equipo.html: estructura de perfiles, sin nombres inventados.
- creditos.html: procedencia y licencias de todas las imágenes.
- docs/: PDFs suministrados.

IMPORTANTE SOBRE IMÁGENES
-------------------------
No eliminar la página creditos.html ni los créditos del pie de página.
La visualización “Social Network Visualization” de Martin Grandjean está bajo CC BY-SA 4.0 y requiere atribución.
